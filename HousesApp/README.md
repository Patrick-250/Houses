# HousesIpadApp

## Description
HousesIpadApp is a web application designed for iPad that allows QLI houses staff to view,and manage houses/rooms.

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
-  **Web Server:**:Apache2
- **Version Control:** Git, GitHub
- **Deployment:** Local windows 2019 Server
